O baseline dos seis testes públicos deixou de representar a main atual. A evidência acima mostra os ficheiros, o motivo e que essas mudanças antecedem esta implementação. Uma futura atualização deve ser uma alteração deliberada do teste, revista com estes diffs. **Não foi feita nesta branch.** A asserção administrativa agregada também precisa de separar contratos que agora mudam legitimamente; trocar apenas o SHA não bastaria para a tornar correta.

Esta auditoria é estrutural e executa os testes existentes. Não é uma alegação de comparação pixel a pixel de todas as páginas de produção. A alteração pública funcional pretendida nesta branch é a origem imutável da imagem e o reconhecimento do novo naming pelos derivados; os testes de SSR, framing, tamanhos e geração continuam a passar.
